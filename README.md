# CampusHub

An interactive academic workspace prototype with Student, Faculty and Admin views.

## GitHub Pages

In repository Settings → Pages, choose Deploy from a branch, then main and /(root), and Save.

## Explore

Use the role switcher to try student assignments, resources and exam tracking; faculty publishing and reviews; and administrator user management.

All information is sample data. Changes last only for the browser session and reset on reload. File submissions are simulated and are not uploaded. The campus assistant is a guided demonstration, not a live AI service. No real authentication or database is connected.

## Local preview

Open index.html or run `python3 -m http.server 4173` from this folder.
